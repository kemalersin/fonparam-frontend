FonParam API

API Adresi: https://api.fonparam.com

Genel Bilgi

FonParam, Türkiye'deki yatırım fonlarının verilerini sunan bir API servisidir. Bu API ile fonların güncel ve geçmiş verilerine erişebilir, karşılaştırmalar yapabilir ve detaylı analizler gerçekleştirebilirsiniz.

  • Tüm yatırım fonlarının güncel verileri
  • Geçmiş performans verileri
  • Gelişmiş filtreleme ve arama
  • Fon karşılaştırma
  • Portföy yönetim şirketi bilgileri

Endpoint'ler

Fonlar

GET /funds GET

Tüm fonları listeler ve filtreleme imkanı sunar.

Örnek:

GET /funds?type=hisse_senedi&page=1&limit=20
GET /funds/top-performing GET

En iyi performans gösteren fonları listeler.

Örnek:

GET /funds/top-performing?funds=AAK,DAH
GET /funds/compare GET

Seçilen fonların performanslarını karşılaştırır.

Örnek:

GET /funds/compare?codes=AAK,GPB
GET /funds/{code}/analyze GET

Belirtilen fon için geçmiş verileri kullanarak yatırım analizi yapar.

Örnek:

GET /funds/AAK/analyze?startDate=year_start&initialInvestment=10000
GET /funds/{code}/historical GET

Belirtilen fonun geçmiş birim pay değerlerini getirir.

Örnek:

GET /funds/AAK/historical?start_date=2023-01-01&end_date=2023-12-31

Portföy Yönetim Şirketleri

GET /companies GET

Tüm portföy yönetim şirketlerini listeler.

Örnek:

GET /companies?page=1&limit=20&sort=total_funds
GET /companies/{code} GET

Belirtilen portföy yönetim şirketinin detaylarını getirir.

Örnek:

GET /companies/APY?include_funds=true

İstatistikler

GET /statistics GET

Günlük bazda toplam fon, şirket, yatırımcı sayısı ve ortalama getiri istatistiklerini listeler.

Örnek:

GET /statistics?start_date=2023-01-01&end_date=2023-12-31
GET /statistics/latest GET

En son güne ait istatistikleri getirir.

Örnek:

GET /statistics/latest
GET /statistics/{date} GET

Belirtilen tarihe ait istatistikleri getirir.

Örnek:

GET /statistics/2023-12-31

Fon Tipleri

GET /fund-types GET

Tüm fon tiplerini ve detaylarını listeler.

Örnek:

GET /fund-types?sort=total_funds&order=DESC
GET /fund-types/{type} GET

Belirtilen fon tipinin detaylarını getirir.

Örnek:

GET /fund-types/hisse_senedi

Önbellek (Cache)

Performansı artırmak için önbellek kullanılmaktadır. Tüm endpoint'ler için önbellek süresi 30 dakikadır.

Rate Limiting

API'ye erişim API Key tabanlı bir sistem üzerinden kontrol edilmektedir:

API Key Olmadan

API Key belirtilmeden yapılan istekler için:

  • 24 saat içinde tüm endpoint'ler için toplam 100 istek hakkı
  • Rate limit aşıldığında 429 (Too Many Requests) hatası döner
  • Rate limit sayaçları IP bazlı tutulur

API Key İle

API Key ile yapılan istekler için özel limit ve kurallar uygulanır. API Key almak için bizimle iletişime geçebilirsiniz.

API Key kullanımı:

curl https://api.fonparam.com/funds \
-H "X-API-Key: api-anahtariniz"
